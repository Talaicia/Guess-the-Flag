#  Guess the Flag – SwiftUI Game

A fun and interactive **Guess the Flag** game built in **SwiftUI**, where players test their world knowledge by identifying flags from different countries.  

---

##  Overview

The app displays three random country flags and asks the player to select the correct one based on the country name shown.  
The player’s score updates after each round, providing instant feedback for correct or incorrect guesses.

---

##  Features

-  Displays **random flags** for each round  
-  Tracks player’s **score and progress**  
-  Smooth **animations** and visual feedback  
-  Great for learning world flags  

---

##  Game Logic

1. Three random flags are displayed.  
2. One of them corresponds to the **target country name** shown in the title.  
3. The player taps a flag:  
   -  Correct: score increases  
   -  Wrong: correct answer is revealed  
4. A new round begins automatically.
